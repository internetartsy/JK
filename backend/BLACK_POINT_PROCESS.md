# BLACK POINT (⚫) PROCESS DEBT DETECTION

## Trigger Events
1. Multiple claimants on same plot
2. Dispute age > 6 months
3. Missing critical documents
4. Aadhaar verification failure
5. Conflicting revenue records
6. Court case pending
7. Overlapping ownership claims
8. Pending tax dues
9. Non-compliance notices
10. Incomplete property survey

# LOAN/BENEFIT APPROVAL PROCESS

Before any loan or scheme benefit disbursement:

## Approval Flow
1. Applicant Submits Request
2. ✅ Verify Plot Ownership (Blockchain)
3. ✅ Check for Black Points (Process Debt)
4. ⚫ BLACK POINT FOUND? ───→ HOLD Application
    * **NO**:
        5. ✅ Title Clear
        6. ✅ Value Assessment
        7. ✅ Loan/Benefit Eligible
        8. ✅ APPROVE LOAN
        9. Disburse Funds
    * **YES (Resolution Required)**:
        5. Contact Tahsildar
        6. Dispute Mediation
        7. Resolve Black Point
        8. Re-verify Status
        9. ✅ Approve if Clear

## Example
1. Farmer requests PM-KISAN enrollment
2. System checks blockchain: ⚫ BLACK POINT DETECTED (Multiple claimants on plot)
3. System HOLDS enrollment
4. Notification sent: "Resolve dispute first"
5. Tahsildar contacts claimants
6. Mediation successful
7. Black point cleared (status: RESOLVED)
8. System approves PM-KISAN enrollment
9. Farmer receives ₹6000/year benefit
